# Data

Raw source data are not stored in this repository due to size and, for dbGaP-derived data,
controlled-access restrictions.

- Full list of the 17 public MAG catalogs used (citations, biome, genome counts): see
  Supplementary Table S1 in the manuscript.
- Raw reads for the 2 dbGaP studies (HMP-A: phs000228.v4.p1; TOPDECC: phs002232.v1.p1)
  require dbGaP controlled-access authorization and are not redistributed here.
- Processed candidate manifests (post length-filter, post-clustering, final validated sets)
  are provided as Supplementary Data: `[DOI / link to be added]`.
